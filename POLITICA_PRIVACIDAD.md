# Política de Privacidad para MiLupa

## ¿Puedo usar la misma política de privacidad de otras apps?

**Sí, puedes reutilizar una política de privacidad existente**, pero debes verificar que cubra todos los datos que MiLupa recopila y los servicios que usa.

## Datos que MiLupa Recopila y Usa

Según el código de la app, MiLupa:

1. **Cámara**: Accede a la cámara para tomar fotos
2. **Almacenamiento**: Guarda las fotos en el almacenamiento del dispositivo
3. **Internet**: Conecta a internet para mostrar anuncios
4. **Appodeal SDK**: Usa Appodeal para mostrar anuncios (banner e intersticiales)
   - Appodeal puede recopilar datos de identificación del dispositivo
   - Datos de uso de la app
   - Datos de publicidad

## Requisitos de la Política de Privacidad

Tu política de privacidad debe mencionar:

### 1. Datos Recopilados
- ✅ **Cámara**: Explicar que se usa para tomar fotos
- ✅ **Almacenamiento**: Las fotos se guardan localmente en el dispositivo
- ✅ **Datos de identificación del dispositivo** (para anuncios)
- ✅ **Datos de uso** (para mejorar la experiencia y mostrar anuncios relevantes)

### 2. Servicios de Terceros
- ✅ **Appodeal**: Mencionar que usas Appodeal para mostrar anuncios
- ✅ **Redes publicitarias**: Appodeal trabaja con múltiples redes publicitarias

### 3. Uso de Datos
- ✅ Las fotos se guardan solo localmente en el dispositivo
- ✅ No se comparten fotos con terceros
- ✅ Los datos se usan para mostrar anuncios personalizados

### 4. Si la app está dirigida a menores de 13 años
- ⚠️ **IMPORTANTE**: Si tu app está dirigida a niños menores de 13 años, debes cumplir con COPPA (Children's Online Privacy Protection Act)
- Debes mencionar esto explícitamente en la política

## Opciones para Crear/Usar una Política de Privacidad

### Opción 1: Reutilizar de otra app (Recomendado si es similar)

Si tienes otra app con una política de privacidad que cubre:
- Cámara
- Almacenamiento
- Anuncios (Appodeal o similar)
- Datos de dispositivo

Puedes usar la misma URL o crear una nueva página con contenido similar.

### Opción 2: Generador de Políticas de Privacidad

Puedes usar generadores gratuitos como:
- **Privacy Policy Generator** (https://www.privacypolicygenerator.info/)
- **FreePrivacyPolicy** (https://www.freeprivacypolicy.com/)
- **Privacy Policy Template** (https://www.privacypolicytemplate.net/)

### Opción 3: Crear una página web simple

Puedes crear una página HTML simple y alojarla en:
- GitHub Pages (gratis)
- Tu propio sitio web
- Cualquier servicio de hosting

## Ejemplo de Estructura Mínima

Tu política de privacidad debe incluir al menos:

```
1. Introducción
   - Nombre de la app: MiLupa
   - Fecha de última actualización

2. Información que Recopilamos
   - Cámara (solo para tomar fotos, no se comparte)
   - Almacenamiento (fotos guardadas localmente)
   - Datos de dispositivo (para anuncios)
   - Datos de uso (para mejorar la app)

3. Cómo Usamos la Información
   - Las fotos se guardan solo en tu dispositivo
   - Los datos se usan para mostrar anuncios relevantes
   - No vendemos datos a terceros

4. Servicios de Terceros
   - Appodeal (para mostrar anuncios)
   - Políticas de privacidad de Appodeal

5. Seguridad
   - Las fotos se guardan localmente
   - No se transmiten a servidores

6. Cambios a esta Política
   - Nos reservamos el derecho de actualizar esta política

7. Contacto
   - Email de contacto
```

## Dónde Alojar la Política

### Opción 1: GitHub Pages (Gratis y Fácil)

1. Crea un repositorio en GitHub
2. Crea un archivo `index.html` con tu política
3. Activa GitHub Pages en la configuración del repositorio
4. Tu URL será: `https://tu-usuario.github.io/tu-repo/`

### Opción 2: Usar la misma URL de otra app

Si ya tienes una política de privacidad para otra app similar, puedes:
- Usar la misma URL
- O crear una página nueva en el mismo sitio

## Cómo Agregar la URL en Google Play Console

1. Ve a **Google Play Console**
2. Selecciona tu app **MiLupa**
3. Ve a **Política y programas** → **Política de la app**
4. En **Política de privacidad**, agrega la URL
5. Guarda los cambios

## Checklist

Antes de subir la política, verifica que mencione:

- [ ] Uso de la cámara
- [ ] Almacenamiento de fotos (local)
- [ ] Uso de Appodeal para anuncios
- [ ] Datos de dispositivo recopilados
- [ ] Que las fotos no se comparten con terceros
- [ ] Información de contacto
- [ ] Fecha de última actualización

## Nota sobre Menores de 13 años

Si tu app está dirigida a niños menores de 13 años:
- Debes cumplir con COPPA
- La política debe ser más específica
- Puede requerir consentimiento de los padres
