## 🔍 Verificar Accesibilidad desde GitHub Pages


### Pasos para Verificar:

1. **Abre esta URL en tu navegador:**
   ```
   https://gastonlesbe.github.io/MiLupa/app-ads.txt
   ```

2. **Deberías ver:**
   ```
   google.com, pub-9841764898906750, DIRECT, f08c47fec0942fa0
   ```

3. **Si ves un error 404:**
   - GitHub Pages no está activo o no está configurado correctamente
   - Sigue los pasos de solución a continuación

## ⚙️ Configurar GitHub Pages (Si es necesario)

Si la URL `https://gastonlesbe.github.io/MiLupa/app-ads.txt` no funciona:

1. Ve a tu repositorio: https://github.com/gastonlesbe/MiLupa
2. Haz clic en **Settings** (Configuración)
3. En el menú lateral, busca **Pages**
4. En **Source** (Fuente), selecciona:
   - **Branch:** `main`
   - **Folder:** `/docs`
5. Haz clic en **Save** (Guardar)
6. Espera 5-10 minutos para que se active

## 📝 Configurar en Google Play Console

Una vez que verifiques que el archivo es accesible desde GitHub Pages:

### Opción 1: En Google Play Console

1. Ve a [Google Play Console](https://play.google.com/console/)
2. Selecciona tu app **MiLupa**
3. Ve a **Presencia en Google Play Store** → **Ficha de Play Store principal**
4. En **Información de contacto**, campo **Sitio web**, ingresa:
   ```
   https://gastonlesbe.github.io/MiLupa
   ```
   O solo:
   ```
   gastonlesbe.github.io
   ```
5. Guarda los cambios

### Opción 2: En AdMob Console (Alternativa)

1. Ve a [AdMob Console](https://apps.admob.com/)
2. Selecciona tu app **MiLupa**
3. Ve a **Monetize** → **app-ads.txt**
4. Ingresa el dominio:
   ```
   gastonlesbe.github.io
   ```
5. Guarda los cambios
